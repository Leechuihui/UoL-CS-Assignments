# 伦敦大学计算机科学课程作业

本仓库按模块收录了我在伦敦大学计算机科学理学学士（BSc Computer Science）学位中的编程课程作业。

## 课程作业

| # | 模块 | 作业 | 说明 |
|---|--------|-----------|-------------|
| 1 | Programming 1 | [黑猫粮仓传奇](01-Programming1-Black-Cat-Granary-Saga/) | 使用 p5.js 开发的 2D 平台跳跃游戏，[在线试玩](https://leechuihui.github.io/Programing-1--final-exam-report-game_project_6/) |

| 4 | 计算机编程导论 | [Case 101: Lina Lovelace](04-IntroToProgramming-Case101-Lina-Lovelace/) | 导论模块的侦探案件作业 |
